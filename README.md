# Posts Manager – Week 6 Fetch API CRUD

## Project Overview
A responsive CRUD application built with JavaScript, Vite and Tailwind CSS using the JSONPlaceholder REST API.

## Features
- GET: Fetch and display posts.
- POST: Create new posts.
- PATCH: Edit existing posts.
- DELETE: Delete posts.
- Filter posts by user.
- Loading and error handling.

## Technologies
- HTML5
- Tailwind CSS
- JavaScript ES Modules
- Vite
- Fetch API
- JSONPlaceholder REST API

## Installation

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start the development server using `npm run dev`.
4. Build using `npm run build`.

## API
https://jsonplaceholder.typicode.com/

Note: JSONPlaceholder simulates write operations. Changes are not permanently stored.

## Learning Outcomes
REST API integration, asynchronous JavaScript, HTTP methods, DOM manipulation and error handling.
